# viho-x-post-style

把加密、金融、美股、财经、AI 或 GitHub 热门话题，写成 X 平台英文长帖：第一人称解释者口吻，钩子开场，分层拆解，数字作证，用“界线段”划清这是什么、不是什么，最后以底线句或警示句收尾。配图为自设计数据卡，主英文辅助中文。

## 什么时候用

- 写 X 平台英文帖子，题材在加密货币、金融、美股、财经新闻、AI、GitHub 热门项目范围内。
- 需要把一个机制、财报、一则新闻或一次市场波动讲清楚，而不是只报一个数字。
- 需要追踪式连续解读同一项目或同一事件的后续。
- 用户说“给我搞笑的贴文”：走梗图工作流（见“梗图 / 搞笑贴文”一节），来源只限 Reddit、9GAG、Imgur。
- 用户说“给我壁纸”“中国风壁纸”或要单独发图片：走中国风壁纸工作流（见“中国风壁纸 / 单独图片发布”一节），图片为超清手机／电脑壁纸，每张必含中国风元素。

不要用于：与上述题材无关的内容；需要用户私人记忆信息的内容（只用公开来源）。

触发：用户说“给我搞笑的贴文”。

来源（只用这三处，刷梗图、最快最新）：

3. **Imgur** — 图片社区，梗图、GIF、短视频，还自带做梗图工具。

选梗规则：
- 只选好笑、有趣的；优先当日热度高、评论多、转发多的梗。
- 硬禁令：不涉及政治，不涉及黄色／黄文／性内容，不涉及任何可能违规或敏感的内容；发之前按 X 平台规则自检一遍（仇恨、骚扰、暴力、色情、误导信息一律不碰）。
- 梗本身若带政治、性暗示、歧视、仇恨元素，哪怕再火也不用。

成稿与交付：
- 每条配一段轻松口语化的英文贴文（短帖，点到为止，别解释梗，别把笑话讲死），不套长帖五段式，不套界线段，不做数据卡。**梗是钩子，正文必须有内容价值（2026-11-15 用户纠正）：借梗带出一个读者能带走的点——一个观察、一个判断、一条经验或一个道理，不能只有“哈哈”就收尾；价值点要贴着梗本身长出来，别硬贴鸡汤。更不能只玩梗、只搞笑，让读者看得不明不白：梗本身若有门槛（内部梗、圈内典故、没头没尾的截图），正文要把意思接住、把话说明白，让没见过这梗的人也能看懂这条在讲什么。**
- 交付物是 X 贴文＋原配的梗图／图片／视频本身（原图原视频直接附上，不重做、不加水印、不裁切改梗）。
- 不放外链、不放联系方式、不放咨询召唤。

## 风格定位

- **第一人称的解释者，不是喊单者。** 用“我”展开（“我以前一直没太在意”“我现在看这类产品，会先确认……”），公司与项目用第三人称。
- **语气冷静、解释性、怀疑而克制，风险意识极强。** 不用感叹词堆砌，不用“必涨”“翻倍”类断言，结论常留有余地（“目前仍要看……”“还得再对一遍……”“还得看汇率、手续费和最终到账”）。
- **风险提示写进正文，不贴模板免责句。** 用区分句提示风险（“不能当成清算保险”“不等于持有股票”“具体以官方规则和页面为准”）。

## 语言

- 主体英文，英文术语与代码原词不翻译（zkTLS、DVC、bytecodeHash、requiredPermissions()、Gauge、TVL、HEC/LEC、GEO、S-1/A、Oracle Price、Execution Price 等）。
- 句子多为中长解释句，逗号层层展开，但每 1–3 句就换段，大量使用单句成段的短段落。
- 英文长帖一般 150–450 词。问候帖固定三行：英文问候／中文／英文意译。
- 几乎不用表情符号（自嘲处最多一个）。不用标签，推广帖除外（见“标签与合作”）。

## 配图：自设计数据卡

- 尺寸 1200×675（渲染 2400×1350），背景为与话题匹配的实拍照片，满幅铺底＋深色渐变罩，保证白字可读。
- **主英文辅助中文**：标题、大数字、数据行用英文，配一行中文辅助。话题行不用实心色块、不用日期、不用来源行——只用一根 10px 主题色竖 tick＋主题色大字距话题字，与标题融为一体。
- 卡上数字必须是已核实的事实，与正文一致；卡上不写来源与日期。

## 配色组合：借鉴载恩撞色法

- 每张卡只用**一组配对（主色＋辅色）**，白字／浅灰字是中性定海，不再加第三个彩色。主辅色相拉开 ΔH≥100°，一高一低。话题组合（深色底提亮版，源自载恩 pairing-library）：**C1 橙×青（加密）主 #FBBF24 辅 #5EEAD4 ← P6；C2 蓝×金（美股财经）主 #7DD3FC 辅 #FBBF24 ← P19/P30；C3 紫×柠（AI）主 #C4B5FD 辅 #BEF264 ← P18；C4 青×粉（GitHub）主 #5EEAD4 辅 #F9A8D4 ← P43；C5 红×青（安全／风险）主 #FCA5A5 辅 #67E8F9 ← P20；C6 金×紫（IPO／大钱）主 #FBBF24 辅 #C4B5FD ← P2**。
- **辅色必须有结构性落点**，与主色形成对话：双数据对色、关键词中英双语呼应、幽灵数字与数据呼应，三选一。孤立的一处着色不算配色组合，宁可不用。
- **配图的第一任务是点击率和好奇心**：卡上必须有一个视觉钩子（反差数字／反常识词），辅色负责把它点出来；主色讲事实，辅色讲“为什么值得点开”；卡是钩子不是摘要，别把正文结论全铺上卡。
- 所有优化都以增加配图设计感为准。
- **整图融合，不切割**：背景照片满幅铺底＋全幅深色渐变罩，文字落在羽化渐变区；禁止照片与纯色面板硬切（上下分块、左右分块、底部实色带均不许），不许用色块边线或实线收边做分割；数据行、引用带一律透明浮在照片上，只用细分隔线区分数据格；可用与话题相关的超大淡色幽灵数字／版本号做背景纹理，但不得与标题或数据重叠、不得影响可读性。

## 版式轮换：每批四张卡，版式各不相同

- 每张配图的文字排版设计都要不同，不然在 X 平台每条贴文同质化太严重。同一批的四张卡不能共用一个模板。
- 每次出新批前，先查已用版式清单，只用没用过的版式；版式用完一轮后，在旧版式上改出明显不同的新结构再用。
- 版式是文字的排版结构（标题位置、数字大小与位置、数据行排列），不是换一张背景图；所有版式都走整图融合，不用实色面板做分区。

## 结构（长帖固定五段式）

1. **钩子**：三类，任选其一——
   - ① 提问式：设问开场；
   - ② 新闻／事实式：今天发生了什么＋数字；
   - ③ 生活化类比式：从日常场景切入机制。
   第一句就是看点，拒绝播报式开头（时间＋机构＋宣布）。
2. **分层拆解**：把机制拆成两到三层讲清（“主要包括两部分”“先……再……”）。
3. **具体数字或场景举例**：每篇长帖都引用具体数字作证据（价格、涨幅、财报数字、池子规模、比例换算）。
4. **“界线”段**：全套风格的标志——说清“这是什么、不是什么”。
5. **收尾**：四类——①底线句（把决定权交回读者）；②警示句；③行动／预告句；④标签块（仅推广帖）。

## 界线段：核心句式

这是最标志性的结构，直接套用。英文帖的界线段标题为 **“Two lines to draw.”**，句式如下：

- **“is not the same as / is not equal to”式区分**：Losing $2,000 is not the start of altcoin season. Cutting a guarantee is not cutting AI investment. An employee vote is not a board decision. A Musk signature is not a vote. Agent-runnable is not human-maintainable. Fast is not the same as good.
- **“X is not Y”**：Six weeks down is not the AI trade breaking. ETF outflows are not long-term holders leaving.
- **“A ≠ B”**：Stars are not usage. A buyback authorization is not a buyback.

中文帖沿用原句式：

- **“不等于／不代表／并不自动等于”式区分**：程序被正确执行，不等于规则合理；来源真实、过程可证明，不等于裁决标准合理；盘前合约报价，不等于持有股票；周末的成交价，不等于基金已经完成了新一天的重置。
- **“只能说明……至于……那是另一回事”**：签名只能说明审计者为这个版本出过凭证，至于代码本身有没有漏洞，那是另一回事。
- **“先……再……”的核查顺序**：先确认自己想要的是哪一种敞口，再看价格属于哪一层；具体数字还得再对一遍。
- **“这可不只是……”**：不只是改几个字母，成本计算方式差别很大；不是随便举个极端例子。
- **“先别急着……”**：看到持仓高度集中，先别急着数有几个大户。
- **对照收束**：“两边用的尺子不一样，看的时候得分开。”
- **“如果……会……吗？”的设问。**

## 数据化

几乎每篇长帖都以具体数字作证据，数字是论证本身，不是装饰：

- 价格与涨幅、财报数字（营收／成本／亏损）、清算数量、集中度百分比；
- 比例换算要算出来：小数点后面多一个零，换成钱之后重量完全不一样（0.001 BTC ≈ 76 美元 vs 0.01 ETH ≈ 22.4 美元，差 3.4 倍）；
- 市场规模与占比、反差对比（744 亿美元市场旁边一个 5 美元的服务）。

数字与来源必须核对，隔夜即时价格重核后再用。

## 结尾

- 底线句：“最终决定仓位和风险边界的，还是自己。”“看对了行情，和买在什么价格，确实是两回事。”英文帖如：“Watch the November 17 earnings first.”“If $67,500 doesn't hold, the next stop is $65,000.”“But the direction is clear: the framework's first user is shifting from humans to agents.”
- 警示句：“更不代表授权之后就没有清算风险。”“谁都不希望自己只记住了利率，却忘了规则也可能改变。”
- 行动／预告句：“明天晚上八点到九点，不见不散！”

# viho-x-post-style

X 平台英文帖子写作风格技能：第一人称解释者口吻，钩子开场，分层拆解，数字作证，用“界线段”划清这是什么、不是什么，最后以底线句或警示句收尾。配图为自设计数据卡，主英文辅助中文，每批四张卡版式各不相同。长帖 150–450 词；冲曝光短帖 50–80 词，全文不带提问。题材除加密、金融、美股、财经、AI、GitHub 外，也可以是有讨论度、争议度、热门的泛娱乐话题（不碰政治敏感话题）；泛娱乐贴文以情绪价值为核心，围绕读者心理学（意识、感觉、知觉、认知、情绪、人格、行为、人际关系、社会关系、人工智能、IQ、性格）展开，表达精确清晰，第一句就是钩子。撰写时可借鉴知乎问答方式，一切以推动 X 账户曝光率为准。

另有梗图／搞笑贴文工作流与中国风壁纸／单独图片发布工作流。（2026-11-16 用户指定：夜世界工作流与山海经妖怪图鉴工作流已从技能库剔除，技能库现无插画工作流。）

## 内容

- `skills/viho-x-post-style/SKILL.md` — 风格技能全文：定位、第一人称全视角、泛娱乐贴文（情绪价值与读者心理学）、冲曝光短版、语言、配图、版式轮换、五段式结构、界线段句式、数据化要求、结尾、标签与合作规则、成稿检查清单，以及梗图／搞笑贴文工作流（来源 Reddit、9GAG、Imgur）、中国风壁纸／单独图片发布工作流（超清手机／电脑壁纸，每张必含中国风元素）。

## 适用

加密、金融、美股、财经新闻、AI、GitHub 热门项目题材的 X 英文帖子，另有讨论度、争议度、热门的泛娱乐题材（不碰政治敏感话题）。长帖 150–450 词，冲曝光短帖 50–80 词，每 1–3 句换段，每条至少一个核过来源和日期的数字。配图 1200×675 自设计数据卡，主英文辅助中文，每批四张卡版式各不相同。

另有梗图／搞笑贴文工作流：用户说“给我搞笑的贴文”时，只从 Reddit（r/memes、r/funny、r/dankmemes、r/Jokes、r/wholesomememes）、9GAG、Imgur 三处抓当日热门梗图，禁政治、禁黄色／性内容、禁敏感违规内容，交付 X 贴文＋原配梗图／图片／视频本身（不做数据卡）。

另有中国风壁纸／单独图片发布工作流：用户说“给我壁纸”“中国风壁纸”或要单独发图片时，发布超清手机壁纸（1080×1920 起）与电脑壁纸（1920×1080 起，优先 2K/4K），每张图必须含中国风元素（传统纹样与图腾、笔墨艺术、建筑空间符号、民俗传统工艺四类），元素融入抓取的图片（Unsplash / Pexels / Pixabay，可商用）或生成的图片中，配简短英文文案，不做数据卡。

## 使用

把 `skills/viho-x-post-style/` 目录作为 skill 安装到 agent 的 skills 目录即可。
